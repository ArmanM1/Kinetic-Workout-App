## 2026-07-16 - Mobile Keyboard & Accessibility for Search Inputs\n**Learning:** Search inputs in custom UI components without `type="search"` fail to trigger native mobile search keyboards, leading to poor UX, and without an `aria-label`, they are inaccessible to screen readers since they rely on visual placeholder text.\n**Action:** Always add `type="search"` and an explicit `aria-label` (e.g., `aria-label="Search exercises"`) to search-specific input components, regardless of placeholder text presence.
