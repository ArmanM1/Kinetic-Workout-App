## 2026-11-02 - Add type="search" and aria-label to search inputs
**Learning:** Standard text inputs on mobile devices show a generic "Return" or "Enter" key on the software keyboard, which isn't optimized for search flows. By setting `type="search"`, mobile OS keyboards (especially iOS) natively display a "Search" key, improving the UX. Additionally, inputs acting as utilities (like a search bar) often lack visible labels, requiring explicit `aria-label` attributes for screen reader support. Finally, native cancel buttons injected by webkit for search inputs can conflict with custom designs, so hiding them using `[&::-webkit-search-cancel-button]:hidden` is necessary.
**Action:** Add `type="search"`, `aria-label`, and `[&::-webkit-search-cancel-button]:hidden` to search inputs in `exercise-browser.tsx` and `active-workout-client.tsx`.
