## 2024-05-15 - [Better Mobile Search Keyboard] | **Learning:** Using `type="search"` on inputs triggers the native mobile search keyboard rather than standard return keys, but adds an ugly native clear button in webkit that needs to be hidden. Also, utility inputs usually lack labels and need aria-labels. | **Action:** Always use `type="search"` for search inputs, add `aria-label`, and hide the webkit cancel button using `[&::-webkit-search-cancel-button]:hidden` for mobile web apps.
