## 2024-06-24 - Enhance mobile search input type
**Learning:** In Next.js/React mobile applications, using `type="search"` on search inputs triggers the native 'Search' key on iOS and Android virtual keyboards instead of the default 'Return' or 'Go' key, significantly improving mobile UX.
**Action:** Always add `type="search"` to any input field that is used primarily for searching or filtering.
