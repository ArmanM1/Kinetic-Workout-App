## 2024-05-24 - Mobile Keyboard Optimization for Search Inputs | **Learning:** Using type="search" on text inputs provides a significantly better native mobile experience, specifically replacing the generic "return" key with a clear "Search" action button on the iOS virtual keyboard. This reduces cognitive load and aligns with platform expectations. | **Action:** Always use type="search" and aria-label="Search" on utility search inputs to optimize the mobile-first UX and ensure accessibility.
