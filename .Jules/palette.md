## 2024-06-10 - Add type="search" to exercise search inputs
**Learning:** Found that search inputs were lacking the `type="search"` attribute, which prevents mobile devices (especially iOS) from showing the optimized "Search" keyboard.
**Action:** Always ensure search input fields use `type="search"` instead of the default text type to improve the mobile input experience, and provide `aria-label` when visible labels are omitted.
