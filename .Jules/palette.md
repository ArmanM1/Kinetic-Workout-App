## 2024-05-18 - Search Inputs on Mobile\n**Learning:** React/Next.js inputs lacking `type="search"` prevent iOS from displaying the native "Search" action key on the software keyboard, creating a subpar mobile experience. Additionally, native WebKit search cancel buttons can clash with custom design systems.\n**Action:** Always use `type="search"` with `[&::-webkit-search-cancel-button]:hidden` and an explicit `aria-label` for utility search inputs.
