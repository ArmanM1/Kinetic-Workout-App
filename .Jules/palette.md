## 2024-05-24 - Mobile Search Input Pattern | **Learning:** For iOS-like mobile web apps, search inputs need `type="search"` to trigger the native Search keyboard key, but require `[&::-webkit-search-cancel-button]:hidden` to prevent native cancel buttons from breaking custom UI designs. Additionally, these utility inputs often lack visible labels, requiring explicit `aria-label` attributes for accessibility. | **Action:** Always use `type="search"`, add `aria-label`, and hide webkit cancel buttons for mobile search inputs.
